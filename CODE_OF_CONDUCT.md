# Code of Conduct

LionLock follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and do not harass anyone in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behavior to the maintainers privately, using the contact button on the [project site](https://thruthseeker.github.io/LionLock_FDE_OSS/#contact). Reports are handled privately, and the maintainers may remove comments, close threads or block participants who break this code.
